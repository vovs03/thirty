# Docs

## Пример дерева каталогов и файлов clicker-игры для Defold (Lua) с подробным описанием

Ниже приведена рекомендованная структура директорий и файлов для вашего проекта, отражающая разделение логики, сцен, интерфейса, ассетов и вспомогательных ресурсов. Такое дерево каталогов будет удобно для командной работы и дальнейшего масштабирования.


```plain
/game-clicker-project
│
├── main.collection          # Главная коллекция (сборка сцен), точка входа игры
│
├── assets/                  # Все игровые ассеты (графика, спрайты, иконки)
│   ├── sprites/             # Спрайты монстриков и UI
│   │   ├── monster_01.png
│   │   ├── monster_02.png
│   │   ├── ... (до 27-ми монстров)
│   │   ├── monster_locked.png      # Силуэт заблокированного монстрика
│   │   └── lock_icon.png           # Иконка замка
│   └── ui/                  # Интерфейсные элементы, кнопки
│       ├── btn_upgrade.png
│       ├── btn_collection.png
│       └── ...
│
├── scripts/                 # Все Lua-скрипты с игровой логикой
│   ├── game_controller.lua      # GameController (смена экранов, главная логика)
│   ├── monster_manager.lua      # MonsterManager (управление монстриками)
│   ├── monster.lua              # Класс Monster
│   ├── currency_manager.lua     # Управление монетами
│   ├── upgrade_manager.lua      # Логика апгрейдов
│   ├── ui_controller.lua        # Контроллер UI логики
│   └── utils.lua                # Вспомогательные утилиты и функции
│
├── gui/                      # GUI-сценарии Defold для экранов и UI
│   ├── game_screen.gui
│   ├── game_screen.gui_script        # Для игрового экрана
│   ├── collection_screen.gui
│   ├── collection_screen.gui_script  # Для коллекции монстриков
│   └── components/                  # GUI-компоненты (опционально)
│       └── monster_item.gui         # GUI-элемент одного монстра в коллекции
│
├── data/                    # Данные о монстриках, апгрейдах и т.п.
│   ├── monsters.json             # Описание всех монстриков (id, name, price, sprite)
│   └── upgrades.json             # Описание улучшений (по монстрикам/уровням)
│
├── main.script               # Точка входа, инициализация коллекций, вызов GameController
├── game.project              # Конфигурация Defold проекта
│
└── docs/                    # (Опционально) Документация по проекту
    ├── uml_diagrams/          # UML-диаграммы
    │   ├── class_diagram.png
    │   ├── usecase_diagram.png
    │   └── activity_diagram.png
    └── README.md              # Краткое описание архитектуры и запуска
```


## Описание основных директорий и файлов

**`/assets/`**
- `sprites/` — изображения для монстриков (цветные и серые), замки и графика для коллекции.
- `ui/` — кнопки, полосы, монетные иконки, элементы интерфейса.

**`/scripts/`**
- `game_controller.lua` — центральная логика игры; управляет состояниями и игроком.
- `monster_manager.lua` — хранение коллекции монстров, открытие новых.
- `monster.lua` — структура одного монстра (поля, методы, апгрейд).
- `currency_manager.lua` — операции с монетами.
- `upgrade_manager.lua` — логика апгрейдов.
- `ui_controller.lua` — связь UI и бизнес-логики.
- `utils.lua` — вспомогательные функции (например, форматирование чисел).

**`/gui/`**
- `game_screen.gui/.gui_script` — визуальная часть основного экрана (clicker).
- `collection_screen.gui/.gui_script` — интерфейс коллекции монстриков.
- `components/` (опционально) — отдельные элементы GUI (например, шаблон для одного монстрика).

**`/data/`**
- `monsters.json` — все параметры монстров: id, имя, цена, пути к спрайтам, начальный статус.
- `upgrades.json` — все параметры возможных улучшений монстриков.

**`/docs/`**
- `plan` - dev_plan_week, day_{1..7}
- `uml_diagrams/` — export-изображения с UML-диаграммами, чтобы быстро находить архитектуру.
- `README.md` — инструкция для команды по архитектуре, запуску и поддержке.

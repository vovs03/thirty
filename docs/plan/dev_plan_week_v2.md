# План разработки MVP игры-кликера с 2 экранами и shop-мержем монстров (1 неделя) v2

> - выходной формат: таблица на каждый день. Все комментарии учитывать что проект пишется на Defold 1.10.4a
> - с учётом разработки именно на Defold 1.10.4a, что влияет на рекомендации по реализации и использованию engine-specific решений.

### День 1: Инициализация и базовая структура

| № | Задача | Тип | Ветка | Комментарий (Defold 1.10.4a) |
| :-- | :-- | :-- | :-- | :-- |
| 1 | Создать проект Defold, настроить сборку | простая | init-project | Создать дефолтный проект, дефолтную сборку, подключить гит-репозиторий |
| 2 | Создать базовый main.collection с двумя экранами (Shop и Game) | простая | screen-scaffolding | Разделить экраны на два gameobjects с коллекциями, добавить переход сцены/экранов |
| 3 | Добавить placeholder-спрайт монстра в Shop | простая | shop-monster-placeholder | Использовать atlas и sprite компоненты, прописать basic rendering |
| 4 | Настроить input для кликов по shop-монстру | средняя | shop-input | Реализовать on_input в скриптах, отслеживать клики мыши, базовая обработка |
| 5 | Сделать базовый game_manager (lua module) для хранения монет и состояния | средняя | game-manager | Хранить счётчик монет, выбранного монстра, доступ к состоянию из разных скриптов |
| 6 | Интегрировать систему состояний (lua msg.post/state machines) для экранов | сложная | state-management | Использовать go.animate, message passing Defold API для переходов и хранение состояния |
